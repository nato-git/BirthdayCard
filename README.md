# BirthdayCard

## 内容
カレンダー表記で誕生日をまとめておくアプリです。誕生日の前日の午前6時になると通知が届き、次の日に誕生日の人がいるとわかります。他の誕生日アプリと違い、名前を登録する際にタグを設定し、自分との関係性を記しておくことができます。

## インストール方法
リリースにあるBirthdayCard.apkをダウンロードしてください。
